How the estimate works

Each Google usage report is priced by modality, then added to the session. Full prompt context is counted again when reported on later turns. Thinking tokens use the text output rate.

Original provider messages and raw metadata are saved before calculation. The pricing version is preserved for offline replay. Reports with missing breakdowns, cached tokens, or unsupported modalities are marked unpriced.

Aggregation assumes each usage message is a generation record, not a session total. Check the raw reports and compare with Google billing before relying on this estimate.
